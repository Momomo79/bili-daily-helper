# B站每日任务助手

一个适配哔哩哔哩网页端的油猴脚本，自动完成个人中心「每日奖励」里的日常任务，并核对经验是否真的到账。

![version](https://img.shields.io/badge/version-1.3.0-fb7299) ![platform](https://img.shields.io/badge/platform-Tampermonkey%20%7C%20Violentmonkey-00a1d6)

## 功能

| 任务 | 说明 |
| --- | --- |
| 登录状态 | 读取 `nav` 接口，未登录直接提示，不做无效重试 |
| 观看视频 | 屏幕外小窗静音播放视频，按设定秒数后关闭，完成「每日观看视频」 |
| 分享视频 | 从排行榜 / 热门 / 稍后再看里挑候选视频，调分享接口，失败自动换下一个 |
| 投币 | 先查该视频是否投过，再按「投币经验目标」补硬币，每枚 +10 经验，默认补到 50 |

脚本会在执行前后各读一次状态做复查：接口说成功、页面却没打勾的，以页面为准；反过来也会重试。**失败不谎报成功。**

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开本仓库的 `B站每日任务助手.user.js`，点 **Raw**，脚本管理器会自动弹出安装页。
   - 也可以把文件下载下来，拖进管理器的「实用工具 → 导入」。

## 使用

打开 `www.bilibili.com` 任意页面，右下角会出现面板：

- **开始执行**：手动跑一遍。
- **最小化 / 隐藏**：收起面板（隐藏后可从 Tampermonkey 菜单重新打开）。
- 面板可拖动，位置会记住。

默认在打开主站时自动跑一次，每天最多自动尝试 2 次（给失败留一次重试的机会）。

### 设置项

| 设置 | 默认 | 含义 |
| --- | --- | --- |
| 观看视频 | 开 | 是否做「每日观看视频」 |
| 分享视频 | 开 | 是否做「每日分享视频」 |
| 投币 | 开 | 是否做「每日投币」。**会消耗真实硬币** |
| 观看秒数 | 60 | 小窗播放多久算完成 |
| 投币经验目标 | 50 | 每日投币想拿多少经验（每枚硬币 +10）；填 10 = 只拿基础那一档 |
| 投币时点赞 | 关 | 投币时是否顺手点个赞 |
| 每天自动运行 | 开 | 打开主站自动执行 |

## 说明与限制

- 只调用站点自己的网页接口（分享、投币、经验奖励、视频列表），不破解、不解锁任何限制、不刷数据。
- 观看任务依赖在主站 `www.bilibili.com` 下开一个隐藏 iframe 播放，跨子域会被 `X-Frame-Options` 拦住，所以脚本只在这几个域生效：`www` / `space` / `t` / `account` / `message`。
- 「每日分享视频」在 B站面板上标注的是「客户端」，网页端接口不一定计入该条，脚本会如实显示成功或失败，不会假装完成。
- 接口字段、DOM 结构随站点改版可能变化，面板日志里会打印返回的 `code` 与 `message`，方便定位。
- 你的账号安全自己负责：脚本不发送任何数据到第三方，所有请求都发往 `*.bilibili.com`。

## 卸载

在脚本管理器里删除本脚本即可；脚本存的配置在管理器里可一并清除（键前缀 `bili-daily-helper:`）。
