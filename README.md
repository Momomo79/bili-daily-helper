![Version](https://img.shields.io/badge/version-2.0.1-blue.svg)
![Platform](https://img.shields.io/badge/platform-Tampermonkey%20%2F%20Violentmonkey-orange.svg)
![Site](https://img.shields.io/badge/site-bilibili.com-fb7299.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

哔哩哔哩网页版每日任务自动化脚本：自动完成**观看视频 / 分享视频 / 投币**，面板内实时显示**当前经验值与升到下一等级大概需要多少天**。

脚本只调用 B 站自己的 Web 接口并复用你已登录的 Cookie；界面挂在独立的 Shadow DOM 里，不改动站点自身结构，也不注入广告或上传任何数据。

## 1. 功能

- **每日任务自动完成**：登录检测 → 分享 → 投币 → 观看，逐项执行并在面板上显示每一步状态，失败可单步重试。
- **经验值预测**：读取账号真实等级与经验，结合今天还能拿到的经验，估算升到下一等级需要多少天。
- **后台观看**：在屏幕外创建静音 `iframe` 播放视频，不打断你正在看的页面，到时长自动关闭。
- **投币防重复**：投币前先查该稿件是否已投过，跳过已投过的视频；支持一次投 1–2 枚。
- **面板**：现代简约样式，跟随系统浅色 / 深色；可拖拽、可收起为胶囊、位置与设置持久化。
- **自动运行**：打开 `www.bilibili.com` 后延迟 6–12 秒自动执行一次，每天最多 2 次（留一次失败重试）。
- **菜单命令**：油猴菜单可立即执行、停止、刷新经验值、显示 / 隐藏面板。
- **完成通知**：结束后通过系统通知汇报成功与失败项数。

## 2. 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 任选一种方式安装脚本：
   - **GreasyFork 一键安装（推荐，后续可自动更新）**：[B站每日任务助手 · 自动完成每日奖励](https://greasyfork.org/zh-CN/scripts/601799-b%E7%AB%99%E6%AF%8F%E6%97%A5%E4%BB%BB%E5%8A%A1%E5%8A%A9%E6%89%8B-%E8%87%AA%E5%8A%A8%E5%AE%8C%E6%88%90%E6%AF%8F%E6%97%A5%E5%A5%96%E5%8A%B1)
   - **本地导入**：打开管理面板 →「添加新脚本」，把 `B站每日任务助手.user.js` 全文粘贴进去并保存；或直接把 `.user.js` 文件拖进浏览器窗口，按提示安装。
3. 打开 [bilibili.com](https://www.bilibili.com/) 并确认已登录，右下角出现「每日任务」胶囊即安装成功。

脚本匹配的站点：

| 域名 | 用途 |
|:---|:---|
| `www.bilibili.com` | 主要使用场景，观看任务只能在这里跑 |
| `space.bilibili.com` | 个人空间，可查看面板与经验值 |
| `account.bilibili.com` | 账号中心，「每日奖励」信息可被脚本读取 |
| `t.bilibili.com` / `message.bilibili.com` | 动态与消息页，面板照常可用 |

## 3. 使用

1. 点右下角胶囊展开面板，面板顶部就是等级与经验卡片。
2. 点「开始执行」，脚本按 **分享 → 投币 → 观看** 的顺序跑；「停止」可随时中断。
3. 点标题栏右侧的齿轮图标展开设置，改动即时保存。
4. 标题栏的「—」收起成胶囊，「×」隐藏面板（隐藏后用油猴菜单重新唤出）。

油猴菜单命令：

| 命令 | 作用 |
|:---|:---|
| ▶ 立即执行每日任务 | 手动跑一轮 |
| ⏹ 停止 | 中断当前执行 |
| 🔄 刷新经验值 | 重新拉取等级与经验 |
| 👁 显示/隐藏面板 | 找回被隐藏的面板 |

> 自动运行只在 `www.bilibili.com` 触发。同一天重复打开页面不会无限刷任务，超过 2 次后会提示改为手动执行。

## 4. 经验值与升级预测

### 每日经验上限

| 来源 | 经验 |
|:---|:---|
| 每日登录 | +5 |
| 每日观看视频 | +5 |
| 每日分享视频 | +5 |
| 每日投币 | 每枚 +10，上限 5 枚共 +50 |
| **合计** | **65 / 天** |

### 计算方式

1. 通过 `x/web-interface/nav` 的 `level_info` 拿到 `current_level`、`current_exp`、`next_exp`；
   其中 `current_exp` 是**累计总经验**，`next_exp` 是**下一等级的阈值**（不是本级增量）。
2. 剩余经验 = `next_exp - current_exp`。
3. 今日还能拿 = 把今天还没做完的任务经验加起来（登录 / 观看 / 分享各 5，投币按已投枚数扣减）。
4. 预计天数 = `ceil((剩余经验 - 今日还能拿) / 65) + 1`，最后 `+1` 是把今天也算进去。
5. `current_level >= 6` 或 `next_exp <= current_exp` 时判定为满级，显示「满级」。

### 举例

```
当前 LV5，经验 13,525 / 28,800
剩余 = 28,800 - 13,525 = 15,275
今日还能拿 65（尚未做任务）
天数 = ceil((15,275 - 65) / 65) + 1 = 235 天
```

面板显示：`距 LV6 还差 15,275 经验` · `约 235 天`。鼠标悬停在经验卡片上可看到完整算式。

> 估算假设你每天都拿满 65 经验。若只做部分任务，实际天数会变长；`coinExpTarget` 设为 0 时脚本不计投币经验。

## 5. 设置项

| 设置 | 默认值 | 说明 |
|:---|:---|:---|
| 观看视频 | 开 | 关闭后不执行观看任务，少拿 5 经验 |
| 分享视频 | 开 | 关闭后不执行分享任务，少拿 5 经验 |
| 投币 | 开 | 关闭后不投币，最多少拿 50 经验 |
| 观看秒数 | 60 | 10–600 秒，60 秒足够触发每日观看 |
| 投币经验目标 | 50 | 0–50，按 10 递增，对应每天投 0–5 枚 |
| 投币时点赞 | 关 | 投币时顺带点赞 |
| 每天自动运行 | 开 | 打开 B 站首页时自动跑一轮 |

脚本内部还有两个不暴露在面板上的配置：`maxRunsPerDay`（默认 2，每天自动执行上限）与面板初始位置偏移，需要时可在存储的 `bili-daily-helper:cfg` 里手改。

> **投币会消耗真实硬币**（每天上限 5 枚）。如果你只想保住每日登录 / 观看 / 分享的 15 点经验，把「投币」关掉即可。

## 6. 数据存储

优先使用油猴的 `GM_getValue / GM_setValue`，不可用时回退 `localStorage`：

| 键 | 内容 |
|:---|:---|
| `bili-daily-helper:cfg` | 全部设置项 |
| `bili-daily-helper:state` | 当天自动执行次数与时间戳 |
| `bili-daily-helper:pos` | 面板拖拽后的坐标 |
| `bili-daily-helper:exp` | 最近一次经验值快照，用于面板秒开 |

清除方式：油猴管理面板里删除该脚本，或手动删掉上述四个键。

## 7. 常见问题

**观看任务一直失败 / 提示播放进度没动**
浏览器会限制后台标签页的媒体播放。把 B 站标签页切到前台，或在站点设置里允许「声音 / 自动播放」，脚本检测到进度停滞会自动重试播放。

**投币失败**
三种常见原因：硬币不足、该稿件今天已投过、账号未完成实名或手机绑定。日志里会给出接口返回码。

**面板显示「未获取 / 经验值读取失败」**
说明 `nav` 接口没返回有效数据，通常是未登录或接口临时异常。登录后点经验卡片右侧的刷新按钮，或用油猴菜单「🔄 刷新经验值」。

**面板不见了**
可能被「×」隐藏了，用油猴菜单「👁 显示/隐藏面板」唤回；也可能是拖到了屏幕外，删除 `bili-daily-helper:pos` 这个键即可复位到右下角。

**升级天数和 B 站显示的不一样**
B 站不提供天数预测，本脚本按「每天拿满 65 经验」推算，属于估算值，不是官方数据。

**会不会被封号**
脚本只调用网页端自身在用的接口，频率也做了人为间隔（分享 1.2 秒、投币 1.5 秒）。但任何自动化都有风险，请自行判断是否使用。
